La media: qué es y cómo se calcula

La media es el número que resume un conjunto de datos en un solo valor: el punto de equilibrio de todos ellos. Aquí ves la fórmula, el procedimiento paso a paso y una calculadora para probarlo con tus propios números.

x̄ = (Σxᵢ) / n
Suma todos los valores y divide entre cuántos son.

01 ¿Qué es la media?

La media (también llamada media aritmética o simplemente "promedio") es un valor que representa el centro de un conjunto de números. Se obtiene sumando todos los datos y repartiendo esa suma en partes iguales entre la cantidad de datos que hay.

Imagina que reúnes las propinas de cinco días de trabajo y las repartes en partes iguales entre esos cinco días: el resultado es la media. No te dice cuánto ganaste cada día en concreto, sino cuánto habría tocado por día si todo se hubiera repartido de forma pareja.

02 La fórmula, explicada término por término

La expresión x̄ = (Σxᵢ) / n se lee así:

  • x̄ — es el símbolo de la media (se pronuncia "x barra").
  • Σ — la letra griega sigma indica una suma: suma todos los valores que tienes.
  • xᵢ — representa cada uno de los datos individuales (x₁, x₂, x₃, ...).
  • n — es el número total de datos que estás promediando.

03 Cómo se calcula, paso a paso

  1. Reúne todos los valores que quieres promediar. Por ejemplo: 4, 8, 6, 5, 3.
  2. Súmalos todos: 4 + 8 + 6 + 5 + 3 = 26.
  3. Cuenta cuántos valores sumaste. En este caso, n = 5.
  4. Divide la suma entre esa cantidad: 26 / 5 = 5.2.
  5. Ese resultado, 5.2, es la media del conjunto.

Ejemplo aplicado: calificaciones de un estudiante

Un estudiante obtuvo estas notas en el semestre:

14 16 12 18 15

Suma: 14 + 16 + 12 + 18 + 15 = 75

Cantidad de notas: n = 5

Media = 75 / 5 = 15

05 No toda "media" se calcula igual

La media aritmética es la más común, pero según el tipo de datos existen otras variantes:

Media aritmética

x̄ = Σxᵢ / n

La estándar: suma y divide. Sirve cuando todos los datos pesan igual.

Media ponderada

x̄ = Σ(xᵢ·wᵢ) / Σwᵢ

Cada dato tiene un peso distinto. Se usa, por ejemplo, cuando un examen final vale más que un parcial.

Media geométrica

x̄ = ⁿ√(x₁·x₂·...·xₙ)

Multiplica los datos en vez de sumarlos. Útil para tasas de crecimiento o porcentajes.

Media armónica

x̄ = n / Σ(1/xᵢ)

Se usa con velocidades o tasas, cuando promediar directamente daría un resultado engañoso.

06 Un cuidado importante

La media es sensible a valores extremos. Si un dato es mucho más grande o pequeño que el resto, "arrastra" la media hacia él. Por ejemplo, en el conjunto 1, 2, 2, 3, 100, la media es 21.6 — un número que no representa bien a la mayoría de los datos. En esos casos conviene mirar también la mediana (el valor central de la lista ordenada).
